Guide des objets géométriques

L’outil de dessin hyperbolique modélise les entités géométriques et les paramètres numériques dans le modèle du disque de Poincaré𝔻={z∈ℂ:|z|<1}\mathbb{D} = \{z \in \mathbb{C} : |z| < 1\}.

1. Points

  • Points libres : Sélectionnez l’outil Point et cliquez n’importe oùà l’intérieur du disque unité. Les points libres peuventêtre déplacés partout dans le disque.

  • Points contraints : Des points peuventêtre créésàl’intersection de deux droites ou cerclesàl’aide de l’outil Intersection.

  • Modifier des points : Cliquez sur un point avec l’outil Sélectionner pour afficher sa barre de propriétés. Vous pouvez le renommer, modifier sa couleur ou changer son verrouillage.

2. Droites et segments géodésiques

  • Droites hyperboliques : Sélectionnez l’outil Droite, puis cliquez sur deux points existants (ou sur des zones vides pour créer des points). La droite géodésique traverse le disque orthogonalement au cercle limite.

  • Segments : Sélectionnez l’outil Segment et cliquez sur deux extrémités pour créer un segment géodésique fini.

  • Style et couleur : Sélectionnez une droite ou un segment pour le renommer ou personnaliser la couleur du tracédans la barre des propriétés.

3. Cercles hyperboliques

  • Création de cercles : Sélectionnez l’outil Cercle. Cliquez sur le premier point servant de centre hyperbolique, puis sur un second point pour définir le rayon.

  • Propriétés : Dans le modèle de Poincaré, les cercles hyperboliques apparaissent comme des cercles euclidiens dont le centre est décalévers l’origine du disque.

4. Nombres et mesures

  • Distance : Sélectionnez l’outil Distance et cliquez sur deux points. Un nouveau nombre représentant la distance hyperbolique s’ajouteàla liste.

  • Angle : Sélectionnez l’outil Angle et cliquez sur trois points pour mesurer l’angle conforme hyperbolique.

  • Paramètres libres : Dans le panneau des nombres, cliquez sur + pour ajouter un paramètre scalaire libre.

  • Ajustement par curseur : Cliquez sur un nombre dans le panneau pour activer le curseur interactif situésous le canevas.
