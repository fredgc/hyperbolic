Hyperbolic Geometry Tool Controls

1. Viewport Navigation

  • Hyperbolic Dragging (Möbius Transformations): Click and drag directly on the Poincarédisk to perform smooth Möbius transformations (PSU(1,1)PSU(1,1)). All hyperbolic lines, circles, and ideal triangles dynamically preserve angles and conformal hyperbolic distance.

  • Euclidean Pan & Zoom:

    • Mouse Wheel / Trackpad: Scroll or pinch to zoom smoothly in or out.

    • Pan/Zoom Tool: Select the Pan/Zoom tool and drag to pan the Euclidean viewport.

    • Reset View: Click the Reset View button in the toolbar or View menu to return to default origin and zoom.

2. Selection & Object Editing

  • Selecting Objects: Select the Select tool and click any point, geodesic, circle, or number.

  • Properties Bar: When an object is selected, a banner appears above the canvas displaying:

    • Object type indicator chip.

    • Inline editable Name field (supports tap-to-edit with Undo/Redo).

    • Interactive Color Picker swatch to choose any custom color.

    • Lock / Unlock toggle and Delete button.

3. Dedicated Interactive Slider

  • Located directly beneath the Poincarédisk canvas.

  • Inactive State: When no number is selected, the slider is disabled with an empty label.

  • Active State: Clicking any numeric parameter in the Numbers panel binds the slider to that number, updating the name, range, and current value.

  • Drag the thumb or use the arrow buttons to smoothly adjust the parameter and watch dependent geometric objects update in real time.

4. Settings & Help

  • Tap the Settings gear in the toolbar to adjust grid division parameters, disk boundary styling, theme modes (Light/Dark/System), and active locale.

  • Open the Help menu for interactive guides, keyboard shortcut reference, and documentation on Poincarédisk geometry.
