---
title: 双曲几何概述
---

双曲几何作图工具是用于在**庞加莱圆盘模型**（$\mathbb{D} = \{z \in \mathbb{C} : |z| < 1\}$）中构建与探索双曲
几何的交互式画布。

在庞加莱圆盘中，欧几里得中立几何公理（不包含平行公设）全部成立，但平行公设不成立：给定一条直线$L$以及线外一点$P \notin L$，存在无数条穿过
$P$且永不与$L$相交的直线。

## 1. 庞加莱圆盘模型

* **点**：双曲空间中的所有点对应于开单位圆盘$|z| < 1$内部的点。单位圆边界$|z| = 1$上的点为无穷远点（理想边界点$\partial
  \mathbb{D}$）。

* **直线（测地线）**：双曲直线表示为与单位圆以直角（$90^\circ$）相交的欧几里得圆弧，以及穿过原点的欧几里得直径。

* **保角性（保角度）**：庞加莱圆盘模型具有保角性：两条双曲直线之间的夹角等于它们在交点处切向量之间的欧几里得夹角。

## 2. 双曲距离与度量

随着点接近单位圆盘边界（$|z| \to 1$），双曲距离呈指数级增长至无穷大。

对于任意两点$u, v \in \mathbb{D}$（复数$x + iy$），**双曲距离** $d(u, v)$为：

$$d(u, v) = \operatorname{arcosh}\left(1 + \frac{2|u - v|^2}{(1 - |u|^2)(1 - |v|^2)}\right) = 2 \operatorname{artanh}\left|\frac{u - v}{1 - \bar{u}v}\right|$$

通常使用伪双曲距离$t = \tanh(d(u, v) / 2) \in [0, 1)$进行代数运算：

$$t = \left|\frac{u - v}{1 - \bar{u}v}\right|$$

对于距原点欧几里得半径为$r = |z|$的点：

$$\rho = \ln\left(\frac{1+r}{1-r}\right) = 2\operatorname{artanh}(r) \iff r = \tanh(\rho / 2)$$

由于边界附近的距离无限拉伸，圆盘边缘位于无穷远处。

## 3. 双曲圆

**双曲圆**（所有与双曲圆心$P \in \mathbb{D}$的双曲距离为$\rho$的点$Q \in \mathbb{D}$的轨迹）是完全落在单位圆盘
内部的**普通欧几里得圆**！

然而，除非$P$位于原点，否则由于度量梯度的存在，该圆的**欧几里得圆心** $C_E$相对于真实的**双曲圆心** $P$会向原点方向偏移。

给定双曲圆心$P$（$p = |P|$）与双曲半径$\rho$（$t = \tanh(\rho / 2)$）：

* **欧几里得圆心**：

  $$C_E = \frac{1 - t^2}{1 - p^2 t^2} P$$

* **欧几里得半径**：

  $$R_E = \frac{(1 - p^2) t}{1 - p^2 t^2}$$

## 4. 尺规作图

经典尺规作图可自然拓展到双曲几何中：

### 双曲圆规

* **圆心+圆上一点（可折叠圆规）**：给定圆心$P$和点$Q$，计算$t = \left|\frac{P - Q}{1 -
  \bar{P}Q}\right|$，绘制圆心为$C_E$、半径为$R_E$的欧几里得圆。

* **圆心+半径/转移距离**：给定圆心$P$和数值半径$\rho$（或参考点$A, B$），构造以此半径为双曲半径的圆。

### 双曲直线（直尺）

穿过任意两个不同点$P, Q \in \mathbb{D}$，存在唯一双曲测地线：

* 若$P, Q$与原点共线，则该线为穿过原点的欧几里得直径。

* 否则，对$P$作关于单位圆的反演点$P' = P / |P|^2$。穿过$P, Q, P'$的欧几里得圆与单位圆正交，圆盘内的弧即为双曲直线。

## 5. 等距变换与莫比乌斯变换

双曲空间是均匀的：每个点具有相同的局部几何性质。平移与旋转由圆盘自同构（莫比乌斯变换）表示：

$$z \mapsto e^{i\theta} \frac{z - a}{1 - \bar{a} z}, \quad |a| < 1, \; \theta \in \mathbb{R}$$

这些变换保持双曲距离、圆以及保角性。
