---
title: 双曲幾何の概要
---

双曲幾何作図ツールは、**ポアンカレ円板モデル**（$\mathbb{D} = \{z \in \mathbb{C} : |z| < 1\}$）における双曲
幾何学を作図・探究するための対話型キャンバスです。

ポアンカレ円板上では、ユークリッド幾何学の公理のうち平行線公準を除くすべてが成り立ちますが、平行線公準は成り立ちません。直線$L$とその上にない点$P
\notin L$に対し、$P$を通り$L$と交わらない直線が無数に存在します。

## 1. ポアンカレ円板モデル

* **点**:双曲空間のすべての点は、開単位円板$|z| < 1$の内部の点に対応します。境界円$|z| = 1$上の点は無限遠点（理想境界
  $\partial \mathbb{D}$）です。

* **直線（測地線）**:双曲直線は、境界円と直交（$90^\circ$）するユークリッド円弧、および原点を通るユークリッド直径として表されます。

* **共形性（角度の保存）**:ポアンカレ円板モデルは共形（等角）です。2本の双曲直線のなす角は、交点における接線ベクトルのユークリッド角と一致します。

## 2. 双曲距離と計量

単位円板の境界（$|z| \to 1$）に近づくにつれて、双曲距離は無限大に向かって指数関数的に増大します。

任意の2点$u, v \in \mathbb{D}$（複素数$x + iy$）の**双曲距離** $d(u, v)$は次の通りです：

$$d(u, v) = \operatorname{arcosh}\left(1 + \frac{2|u - v|^2}{(1 - |u|^2)(1 - |v|^2)}\right) = 2 \operatorname{artanh}\left|\frac{u - v}{1 - \bar{u}v}\right|$$

代数的に扱いやすい擬双曲距離$t = \tanh(d(u, v) / 2) \in [0, 1)$もよく利用されます：

$$t = \left|\frac{u - v}{1 - \bar{u}v}\right|$$

原点からユークリッド距離$r = |z|$にある点について：

$$\rho = \ln\left(\frac{1+r}{1-r}\right) = 2\operatorname{artanh}(r) \iff r = \tanh(\rho / 2)$$

境界に近づくほど距離が拡大するため、円板の縁は無限に遠い場所にあります。

## 3. 双曲円

双曲中心$P \in \mathbb{D}$から双曲距離$\rho$にあるすべての点の集合である**双曲円**は、単位円板の内側に完全に収まる**通常のユー
クリッド円**です。

ただし、$P$が原点にある場合を除き、計量の勾配により円の**ユークリッド中心** $C_E$は真の**双曲中心** $P$から原点方向へ引き寄せられます。

中心$P$（$p = |P|$）と半径$\rho$（$t = \tanh(\rho / 2)$）について：

* **ユークリッド中心**:

  $$C_E = \frac{1 - t^2}{1 - p^2 t^2} P$$

* **ユークリッド半径**:

  $$R_E = \frac{(1 - p^2) t}{1 - p^2 t^2}$$

## 4. 定規とコンパスによる作図

古典的な作図は双曲空間にも自然に拡張されます：

### 双曲コンパス

* **中心+円上の点**:中心$P$と通過点$Q$から$t = \left|\frac{P - Q}{1 - \bar{P}Q}\right|$を求め、中
  心$C_E$、半径$R_E$のユークリッド円を描きます。

* **中心+半径**:中心$P$と数値半径$\rho$（または2点$A, B$の距離$\rho = d(A, B)$）から、指定された半径の双曲円を作図し
  ます。

### 双曲直線（定規）

任意の2点$P, Q \in \mathbb{D}$を通る双曲測地線は一意に存在します：

* $P, Q$と原点が同一直線上にある場合、直線は原点を通る直径です。

* それ以外の場合、円反転により$P' = P / |P|^2$を求めます。$P, Q, P'$を通る一意の円は単位円と直交し、円板内の弧が双曲直線となりま
  す。

## 5. 等長変換とメビウス変換

双曲空間は一様であり、すべての点が同一の局所幾何構造を持ちます。移動や回転は円板の自己同型写像（メビウス変換）で表されます：

$$z \mapsto e^{i\theta} \frac{z - a}{1 - \bar{a} z}, \quad |a| < 1, \; \theta \in \mathbb{R}$$

これらの変換は双曲距離、円、共形角を保存します。
