A **Ferramenta de Desenho Hiperbólico**éum aplicativo interativo projetado
para construir, visualizar e explorar figuras geométricas no modelo de disco
de Poincaréda geometria hiperbólica.

Permite realizar construções clássicas com régua e compasso no disco de
Poincaré($\mathbb{D} = \{z \in \mathbb{C} : |z| < 1\}$), onde o quinto
postulado de Euclides nãoéválido.

O código-fonte estádisponível no GitHub:
[https://github.com/fredgc/hyperbolic][github].

Encontrou um erro? [Abra uma issue no GitHub][issues].

Outros aplicativos estão em [www.gchouse.org][gchouse].

## Privacidade e retenção de dados

As preferências são armazenadas exclusivamente no seu dispositivo
(`SharedPreferences` / `localStorage`). Nenhum dado pessoalécoletado.
