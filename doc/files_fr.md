---
title: Gestion des fichiers
---

Le tiroir latéral gauche (accessible via l'icône de menu) propose des options
pour les fichiers et le presse-papiers :

## 1. Options de fichier

* **Nouveau** : Efface la scène actuelle pour commencer un dessin sur un
  canevas vierge.

* **Ouvrir** : Permet de charger un dessin depuis :

  * **Données locales** : Choisissez des fichiers dans le stockage de
    l'appareil.

  * **Google Drive** : Accédezàvos dessins synchronisés sur Google Drive.

  * **Charger depuis le presse-papiers** : Un dessin peutêtre enregistrésous
    forme de texte et collédirectement dans l'application.

* **Enregistrer / Enregistrer sous** : Enregistre le dessin en cours dans le
  stockage local, sur Google Drive ou dans le presse-papiers.

* **Partager / Exporter** : Exporte les données du dessin vers le
  presse-papiers ou les télécharge au format JSON.

## 2. Modifications non enregistrées et points de sauvegarde

Lorsque des modifications ontétéapportéesàun dessin, un indicateur signale
qu'elles ne sont pas enregistrées. Fermer ou quitter la page vous inviteà
enregistrer votre travail. L'annulation jusqu'au dernierétat enregistrémarqueà
nouveau le document comme sauvegardé.
