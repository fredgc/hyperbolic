Über Hyperbolic (v{{ VERSION }})

Das Hyperbolische Zeichenwerkzeug ist eine interaktive Anwendung zum Konstruieren, Visualisieren und Erkunden geometrischer Diagramme im Poincaré-Kreisscheibenmodell der hyperbolischen Geometrie.

Sie ermöglicht klassische Konstruktionen mit Zirkel und Lineal angepasst an die Poincaré-Scheibe (𝔻={z∈ℂ:|z|<1}\mathbb{D} = \{z \in \mathbb{C} : |z| < 1\}), in der Euklids Parallelenaxiom nicht gilt.

Der Quellcode ist auf GitHub verfügbar: [https://github.com/fredgc/hyperbolic][github].

Haben Sie einen Fehler gefunden? [Erstellen Sie ein Problem auf GitHub][issues].

Weitere Anwendungen finden Sie auf [www.gchouse.org][gchouse].

Datenschutz und Datenspeicherung

Einstellungen werden lokal auf Ihrem Gerät gespeichert (SharedPreferences / localStorage). Es werden keine personenbezogenen Daten erhoben.
