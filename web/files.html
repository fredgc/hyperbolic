File Management

The left-hand drawer (accessible via the Menu icon) provides file and clipboard options:

1. File Options

  • New: Clears the current scene to start drawing on a blank canvas.

  • Open: Prompts you to load a drawing from:

    • Local Data: Pick files from the device’s storage.

    • Google Drive: Access synced drawings from your Google Drive files.

    • Load from Clipboard: A drawing can be saved as text and pasted into the app this way.

  • Save / Save As: Saves the current drawing directly to local storage, Google Drive, or clipboard.

  • Share / Export: Export drawing data to the clipboard or download as JSON.

2. Unsaved Changes & Checkpoints

When changes have been made to a drawing, an indicator shows that changes are unsaved. Closing or navigating away prompts to save your work. Undoing back to the last saved state marks the document as clean again.
