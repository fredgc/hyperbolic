À propos de Hyperbolic (v{{ VERSION }})

L’Outil de dessin hyperbolique est une application interactive conçue pour construire, visualiser et explorer des figures géométriques dans le modèle du disque de Poincaréde la géométrie hyperbolique.

Elle permet d’effectuer des constructionsàla règle et au compas adaptées au disque de Poincaré(𝔻={z∈ℂ:|z|<1}\mathbb{D} = \{z \in \mathbb{C} : |z| < 1\}), oùle postulat des parallèles d’Euclide ne s’applique pas.

Le code source est disponible sur GitHub : [https://github.com/fredgc/hyperbolic][github].

Un bug ou une suggestion ? [Signalez un problème sur GitHub][issues].

D’autres applications sont disponibles sur [www.gchouse.org][gchouse].

Confidentialité et conservation des données

Les paramètres sont enregistrés localement sur votre appareil (SharedPreferences / localStorage). Aucune donnée personnelle n’est collectée.
